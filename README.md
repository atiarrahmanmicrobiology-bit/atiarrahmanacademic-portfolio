# Md. Atiar Rahman | Academic & Research Portfolio

A responsive, static academic portfolio website built with HTML, CSS, and JavaScript. It is ready to deploy on Vercel.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a GitHub repository and upload all files in this folder.
2. Sign in at https://vercel.com/ and choose **Add New → Project**.
3. Import the GitHub repository.
4. Framework Preset: **Other**.
5. Build Command: leave blank.
6. Output Directory: `.` (or leave the default if Vercel detects the static site).
7. Click **Deploy**.

You can also use Vercel CLI from this folder:
```bash
npm install -g vercel
vercel
```

## Personalize before publishing
Search and replace the placeholders in `index.html`:
- `your.email@example.com` with your professional email.
- Add your LinkedIn profile URL.
- Add a profile photograph if desired.
- Add undergraduate education, exact degree title, passing year, CGPA (if you wish).
- Add verified publication details and DOI links only after publication.
- Review the skills list and keep only skills you can confidently demonstrate.

## Notes
This project intentionally avoids inventing an email address, publication record, academic grade, or undergraduate details. Research descriptions are concise portfolio summaries and should be checked against your final thesis before public use.
